## 3. Mapeo de Métricas y Umbrales

| Recurso | Linux (POSIX) | Windows Nativo (`os.name == 'nt'`) | Umbral de Admisión | Mapeo / Justificación |
| :--- | :--- | :--- | :--- | :--- |
| **Candado** | `fcntl.flock(fh, LOCK_EX \| LOCK_NB)` | `msvcrt.locking(fh.fileno(), LK_NBLCK, 1)` | Exclusivo no bloqueante | En Windows el archivo debe tener >=1 byte; se asegura `b'\0'` antes del lock. Liberación con `LK_UNLCK`. |
| **CPU** | `os.getloadavg()[0]` | `Get-CimInstance Win32_Processor` (LoadPercentage) | `FACTOR_CARGA_MAXIMA = 1.5` | En Linux: `carga_1m > nucleos * 1.5`. En Windows: `cpu_pct > 150.0%` (mapeo `load/nucleos * 100`). Caché de 5 s y timeout de 10 s. |
| **Load Avg** | `os.getloadavg()[0]` | `None` (`NO DATA`) | N/A en Windows | Windows no dispone de concepto de load average; se reporta explícitamente `NO DATA` (nunca 0). |
| **RAM Disponible** | `/proc/meminfo` (MemAvailable) | `GlobalMemoryStatusEx` (`ullAvailPhys`) | `MIN_MEMORIA_DISPONIBLE_MB = 1536.0` (1.5 GB) | Mismo umbral exacto en MB. Si `memoria_disponible_mb < 1536.0` rechaza. |
| **RAM % Uso** | N/A | `GlobalMemoryStatusEx` (`dwMemoryLoad`) | Informativo | Calculado en tiempo real por el SO (0-100%). |
| **Swap** | `/proc/meminfo` (SwapFree) | `GlobalMemoryStatusEx` (`ullAvailPageFile`) | `MIN_SWAP_LIBRE_MB = 256.0` | Representa pagefile disponible en Windows. Si swap_libre < 256 MB rechaza. |

## 4. Pruebas Realizadas en `tests/test_gobernanza_recursos_windows.py`
1. `test_estado_windows`: Valida que `medir()` devuelve `cpu_pct` (0-100), `ram_pct` (0-100), `memoria_disponible_mb` > 0 y `carga_1m is None`. Valida ejecución CLI con rc=0.
2. `test_candado_real_dos_procesos`: Proceso A toma el turno durante 6 s (`time.sleep(6)`). Proceso B con `--no-esperar` intenta adquirir el turno concurrentemente y es rechazado con rc!=0 y mensaje de ocupado. Al terminar A, el siguiente proceso toma el turno exitosamente con rc=0.
3. `test_ejecutar_comando_falla_libera_candado`: Proceso con comando fallido (`sys.exit(42)`) propaga el código 42 y libera el candado en el bloque `finally`, permitiendo que el siguiente comando se ejecute sin bloqueos residuales.

## 5. Hallazgos y Decisiones de Arquitectura
- **Aislamiento Dinámico de Estado**: Se implementaron `get_directorio_estado()`, `get_ruta_candado()` y `get_ruta_titular()` que leen `GOBERNANZA_LOCK_DIR` o `ULTRARENTABLE_RUNTIME_DIR` o el flag `--lock-dir`. Esto permite que los tests y procesos independientes usen carpetas aisladas sin interferir con el candado global de la máquina.
- **Soporte de `--` en CLI**: Se añadió soporte robusto para el separador `--` mediante `parse_intermixed_args` y división previa de `sys.argv`, permitiendo ejecutar comandos con banderas internas (como `python -c "..."`) tanto en Windows PowerShell como en entornos POSIX.
- **Prioridad de Proceso en Windows**: `_rebajar_prioridad()` utiliza `ctypes.windll.kernel32.SetPriorityClass` con `BELOW_NORMAL_PRIORITY_CLASS` (0x00004000) en Windows, emulando el comportamiento de `nice` en POSIX.
- **Zero-Mocks & Fail-Closed**: Sin uso de generadores sintéticos ni mocks. Si la medición de CPU o RAM falla, la admisión rechaza con `NO DATA` protegiendo la estabilidad del equipo.
