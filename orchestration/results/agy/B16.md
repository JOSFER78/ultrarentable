## 2. Detalle Técnico de las Modificaciones

### 2.1 Soporte de `BACKEND_URL` en el Frontend Web
- **`apps/web/next.config.mjs`**: Se configuró `backendUrl` para resolver prioritariamente `process.env.BACKEND_URL`, manteniendo el fallback a `process.env.ULTRARENTABLE_API_URL` y el valor por defecto `http://127.0.0.1:8000`.
- **`apps/web/lib/api.ts`**: Se actualizó `BASE_URL` en modo SSR para leer `process.env.BACKEND_URL || process.env.ULTRARENTABLE_API_URL || "http://127.0.0.1:8000"`.
- **Verificación de tipos**: `npx tsc --noEmit -p apps/web` ejecutado sin errores (`rc=0`).

### 2.2 Script de Control de Ciclo de Vida (`scripts/orq/web_local.ps1`)
Desarrollado estrictamente en PowerShell 5.1 (sin sintaxis `&&` ni `??`) con soporte para 4 acciones:
- **`-Arrancar` (por defecto)**:
  - Lanza Uvicorn con `services.api.app.main:app` en `http://127.0.0.1:8100` en segundo plano desacoplado (`Start-DaemonProcess` / WMI).
  - Espera confirmación HTTP 200 de la API.
  - Verifica la presencia del build de producción en `apps/web/.next` (o lo genera con `npm run build`).
  - Lanza el servidor Next.js en producción (`npm run start -- -p 3100`) con `BACKEND_URL=http://127.0.0.1:8100`.
  - Registra PIDs reales en `orchestration/site/local.pids.json` y ejecuta el diagnóstico `-Estado`.
- **`-Estado`**:
  - Inspecciona los PIDs activos y la pertenencia de puertos (`Get-NetTCPConnection`).
  - Sondea en tiempo real los 6 endpoints: API Root (`8100/`), API Version (`8100/api/v1/version`), API System Health (`8100/api/v1/system/health`), Web Home (`3100/`), Web Estrategias (`3100/estrategias`), Web Prop-Firms (`3100/prop-firms`).
  - Extrae la versión canónica del motor (`5.18.0`) y el estado de la base de datos física (`STATE_DB_PATH`).
- **`-Reconstruir`**:
  - Detiene el proceso Web activo.
  - Ejecuta `npm run build` en `apps/web`.
  - Reinicia la Web en el puerto 3100 y actualiza `local.pids.json`.
- **`-Parar`**:
  - Detiene ordenadamente los procesos API y Web y libera los puertos locales 8100 y 3100.
  - Cumple la regla **NUNCA RM**: renombra `local.pids.json` a `local.pids.<yyyyMMdd_HHmmss>.json`.

### 2.3 Documentación Operativa y Gitignore
- **`orchestration/OPERACION_WEB_LOCAL.md`**: Manual operativo completo con la tabla de puertos, comandos de arranque, estado, reconstrucción y parada.
- **`.gitignore`**: Se añadieron `orchestration/site/*.log` y `orchestration/site/local.pids*.json`.
