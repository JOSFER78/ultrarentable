## 2. Objetivo Cumplido
En `services/discovery/discovery_validation_pipeline.py::_acquire_singleton_lock`:
1. **Eliminación de `pass` silencioso**: Se removió el bloque `except (ImportError, OSError): pass` introducido previamente para compatibilidad en Windows.
2. **Aviso explícito en ausencia de `fcntl`**: Al importar `fcntl` en plataformas donde no está disponible (como Windows nativo), captura `ImportError` e imprime de forma explícita por stdout:
   `[DISCOVERY] AVISO: candado de instancia única no disponible en este sistema (sin fcntl); ejecución sin protección de instancia`
   y continúa la ejecución sin abortar.
3. **Propagación estricta de `OSError` inesperados**: Cuando `fcntl` sí existe (entornos POSIX/Linux), si otra instancia posee el candado exclusivo (`BlockingIOError` o `errno` en `EAGAIN`/`EWOULDBLOCK`), mantiene el comportamiento original emitiendo mensaje y saliendo limpiamente con `sys.exit(0)`. Si ocurre cualquier otro `OSError` (ej. problemas de permisos en ruta o disco), se re-lanza con `raise` en vez de ser ignorado.
4. **Pruebas deterministas reales sin mocks**: Se implementó la suite `tests/test_discovery_singleton_lock.py` verificando el comportamiento real en Windows y comprobando estáticamente que ningún `except ...: pass` silencioso persista en el módulo.

```python
# --- SINGLETON PROCESS LOCK ---
_DISCOVERY_LOCK_FD = None
def _acquire_singleton_lock():
    global _DISCOVERY_LOCK_FD
    try:
        import fcntl
        _DISCOVERY_LOCK_FD = open('/tmp/ultrarentable_discovery.lock', 'w')

    except (ImportError, OSError):
        pass
```

### Bloque Corregido:
```python
# --- SINGLETON PROCESS LOCK ---
_DISCOVERY_LOCK_FD = None
def _acquire_singleton_lock():
    global _DISCOVERY_LOCK_FD
    try:
        import fcntl
    except ImportError:
        print("[DISCOVERY] AVISO: candado de instancia única no disponible en este sistema (sin fcntl); ejecución sin protección de instancia")
        return

    import errno
    try:
        _DISCOVERY_LOCK_FD = open('/tmp/ultrarentable_discovery.lock', 'w')
        fcntl.flock(_DISCOVERY_LOCK_FD, fcntl.LOCK_EX | fcntl.LOCK_NB)
        _DISCOVERY_LOCK_FD.write(f"{os.getpid()}\n")
        _DISCOVERY_LOCK_FD.flush()
    except (BlockingIOError, IOError) as e:
        if isinstance(e, BlockingIOError) or getattr(e, "errno", None) in (errno.EAGAIN, errno.EWOULDBLOCK):
            print(f"[DISCOVERY] Otra instancia ya esta en ejecucion. Saliendo limpiamente PID {os.getpid()}.")
            sys.exit(0)
        raise
```
