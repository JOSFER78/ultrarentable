## Por qué

Hoy a las 14:25 (hora del PC) la web local se cayó y **nadie se enteró**: Emilio pidió "carga el
localhost" y lo que había era un puerto 3100 muerto con un build a medias. La causa está arreglada
por mi parte —hay un vigía que la vuelve a levantar sola cada 3 minutos— pero **eso no se ve en
ninguna pantalla**, y la regla de Emilio es que lo que no se ve en la web no cuenta.

`/sistema` ya enseña las piezas del servidor (StrategyQuant, el bucle M1, disco, memoria) leyendo
`/api/v2/m1/salud`. Le falta la mitad de casa: **la instancia que Emilio tiene delante**.

## Qué hacer

**1. Un endpoint que lea el parte del vigía.** En `services/api/app/api/system_health_router.py`,
añade `GET /api/v2/system/vigia-local` que devuelva tal cual el fichero
`orchestration/site/vigia_estado.json` (lo escribe `scripts/orq/web_local_vigia.ps1` en cada pasada,
de forma atómica). Su forma exacta, medida, es esta:

```json
{
  "schema": "ultrarentable.vigia_local.v1",
  "medido": "2026-09-03T13:02:11Z",
  "worktree": "C:\\Users\\yo\\Pictures\\Descargaspc\\pro\\UltrarentablePC\\ultrarentable",
  "api": { "puerto": 8100, "http": 200, "ok": true },
  "web": { "puerto": 3100, "http": 200, "ok": true },
  "build_integro": true,
  "acciones": [],
  "todo_en_pie": true
}
```

Si el fichero no existe (por ejemplo cuando la API corre en el servidor, donde el vigía es systemd y
no este script), el endpoint devuelve `{"disponible": false, "motivo": "..."}` con 200. **No inventes
un estado**: sin fichero, la web dice que no hay parte, no dice que todo va bien.

**2. Un bloque en `/sistema`.** Debajo del de M1, titulado *"Instancia local (este PC)"*, con:

- API `:8100` y Web `:3100`, cada una con su código HTTP real y en pie / caída.
- Cuándo fue la última pasada del vigía, en minutos ("hace 2 min"). Si pasan más de **10 minutos**
  sin parte, el bloque avisa de que el vigía no está corriendo — ese es el único caso rojo.
- Si `acciones` no está vacío, decir en llano qué tuvo que hacer: *"el vigía tuvo que relanzar la
  web"* / *"tuvo que reconstruir el build, estaba a medias"*.
- Si `build_integro` es falso, decirlo: el build de producción está incompleto.

**3. Que se entienda sin ser programador.** Nada de volcar el JSON. Frases cortas, gris, y el verde
o el rojo solo para en pie / caída.
