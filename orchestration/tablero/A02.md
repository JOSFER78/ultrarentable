## Por qué

El servidor tiene SSH abierto a internet y `fail2ban` no está instalado (`which fail2ban-server` no
devuelve nada, 2026-09-03 02:45 UTC). Con clave y sin contraseña el riesgo es bajo, pero fail2ban
corta el ruido de fuerza bruta y deja registro de quién lo intenta.

## Qué hacer

Después de A01, nunca antes.

```bash
apt-get install -y fail2ban
systemctl enable --now fail2ban
```

## Aceptación

```bash
systemctl is-active fail2ban        # esperado: active
fail2ban-client status sshd         # esperado: responde con la jaula sshd, sin error
```

## Prohibido

Cambiar la configuración por defecto de las jaulas; tocar `sshd_config`; banear rangos a mano.
