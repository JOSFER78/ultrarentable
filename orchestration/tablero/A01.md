## Por qué

**Ha empeorado.** Medido por el orquestador el 2026-09-03 a las 01:33 UTC, con StrategyQuant X ya
instalado y corriendo en el servidor:

```
$ ss -ltnp | grep 5050
LISTEN 0 50  0.0.0.0:5050  0.0.0.0:*  users:(("StrategyQuantX",pid=29693,fd=100))
$ ufw status
Status: inactive
$ grep -c auth_basic /etc/nginx/sites-available/default
0
```

`0.0.0.0:5050` significa **abierto a internet**, y la API de StrategyQuant **no pide ninguna
credencial**: quien alcance ese puerto controla la minería, los proyectos y la exportación de
ficheros de la máquina. Con la licencia de Emilio dentro. Sigue además todo lo de antes:

- Sin cortafuegos (`ufw inactive`, `iptables -S INPUT` con política `ACCEPT`).
- Escritorio remoto público **sin contraseña**: `curl https://88-99-210-167.sslip.io/novnc/vnc.html`
  devuelve **200** y la URL trae `autoconnect=true`. Cualquiera con el enlace entra como root.
- `x11vnc` con `-nopw` escuchando en `[::]:5900`, y la máquina tiene IPv6 pública
  `2a01:4f8:10a:3b9a::2/64`.
- `websockify` en `0.0.0.0:6080`, saltándose nginx.

Esta tarea es lo primero de todo. No hace falta parar StrategyQuant: el cortafuegos deja el 5050
accesible desde la propia máquina, que es lo único que necesita.

## Qué hacer

`ssh sqx-hetzner`. **En este orden.** El bloque 1 abre el 22 antes de activar nada, así que no
puede dejar a nadie fuera.

**1. Cortafuegos (esto es lo urgente)**

```bash
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp
ufw --force enable
ufw status verbose
```

Deshacer: `ufw disable`.

**2. Contraseña en el escritorio remoto**

La contraseña **la elige Emilio**: pídesela, no la inventes. Si no puedes pedírsela, haz solo el
bloque 1, deja la tarea en `ENTREGADO` y dilo en el parte.

```bash
apt-get update -qq && apt-get install -y apache2-utils
htpasswd -c /etc/nginx/.htpasswd emilio     # la pide dos veces
cp /etc/nginx/sites-available/default /root/nginx-default.bak
sed -i 's|^\(    location /novnc/ {\)|\1\n        auth_basic "Ultrarentable";\n        auth_basic_user_file /etc/nginx/.htpasswd;|' /etc/nginx/sites-available/default
sed -i 's|^\(    location = /novnc/websockify {\)|\1\n        auth_basic "Ultrarentable";\n        auth_basic_user_file /etc/nginx/.htpasswd;|' /etc/nginx/sites-available/default
nginx -t && systemctl reload nginx
```

Deshacer: `cp /root/nginx-default.bak /etc/nginx/sites-available/default && systemctl reload nginx`.

Y desde el PC, para probar que no te has cerrado la puerta:

```bash

```

Comprobación extra que vale oro: desde el PC, `curl -s -m 8 http://88.99.210.167:5050/` debe
**fallar** (tiempo agotado o conexión rechazada). Si contesta, el 5050 sigue abierto y la tarea no
está hecha.

## Prohibido

Abrir el 5050 ni ningún otro puerto; parar o reiniciar StrategyQuant (está trabajando); tocar
`sshd_config`; cambiar claves SSH; reiniciar el servidor.
