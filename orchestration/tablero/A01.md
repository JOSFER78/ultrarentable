## Por qué

El servidor `88.99.210.167` (Hetzner, recién entregado, donde va a vivir StrategyQuant X con la
licencia de Emilio) está **abierto a internet**. Medido por el orquestador el 2026-09-03 a las
02:45 UTC, cada punto con su comando:

- `ufw status` → `inactive`; `iptables -S INPUT` → política `ACCEPT`. **No hay cortafuegos.**
- `curl -o /dev/null -w '%{http_code}' https://88-99-210-167.sslip.io/novnc/vnc.html` → **200**, sin
  pedir contraseña, y la URL lleva `autoconnect=true`. Cualquiera con el enlace entra a un
  escritorio gráfico **como root**.
- `grep -c auth_basic /etc/nginx/sites-available/default` → **0**. Las dos `location` que hacen
  `proxy_pass` a `127.0.0.1:6080` no piden nada.
- `ps -eo cmd | grep x11vnc` → corre con **`-nopw`** (sin contraseña) y `ss -ltn` lo muestra en
  `[::]:5900`; `ip -6 addr` da IPv6 pública `2a01:4f8:10a:3b9a::2/64`. Segunda puerta, independiente.
- `websockify` en `0.0.0.0:6080`: se puede saltar nginx.

Además `sqcli` (StrategyQuant headless) **no tiene autenticación**: quien alcance su puerto 5050
controla la minería. Por eso el cortafuegos va primero, antes de instalar nada más.

## Qué hacer

Entrar con `ssh sqx-hetzner`. **En este orden.** El bloque 1 abre el 22 antes de activar nada, así
que no puede dejar a nadie fuera.

**1. Cortafuegos**

```bash
ufw allow 22/tcp && ufw allow 80/tcp && ufw allow 443/tcp
ufw --force enable
ufw status verbose
```

Deshacer: `ufw disable`.

**2. Contraseña en el escritorio remoto**

La contraseña **la elige Emilio**: pídesela. No la inventes ni dejes una por defecto. Si no puedes
pedírsela, haz solo el bloque 1, pon `estado: ENTREGADO` y dilo en el parte.

```bash
apt-get update -qq && apt-get install -y apache2-utils
htpasswd -c /etc/nginx/.htpasswd emilio     # la pide dos veces
cp /etc/nginx/sites-available/default /root/nginx-default.bak
sed -i 's|^\(    location /novnc/ {\)|\1\n        auth_basic "Ultrarentable";\n        auth_basic_user_file /etc/nginx/.htpasswd;|' /etc/nginx/sites-available/default
sed -i 's|^\(    location = /novnc/websockify {\)|\1\n        auth_basic "Ultrarentable";\n        auth_basic_user_file /etc/nginx/.htpasswd;|' /etc/nginx/sites-available/default
nginx -t && systemctl reload nginx
```

Deshacer: `cp /root/nginx-default.bak /etc/nginx/sites-available/default && systemctl reload nginx`.

## Aceptación

```bash
curl -s -o /dev/null -w 'novnc: %{http_code}\n' https://88-99-210-167.sslip.io/novnc/vnc.html   # esperado: 401
ufw status verbose | head -12                          # esperado: Status: active con 22/80/443
grep -c auth_basic /etc/nginx/sites-available/default  # esperado: 4
nginx -t                                               # esperado: test is successful
ss -ltn | grep -E ':(5900|6080)'                       # siguen escuchando en local: correcto
```

Y desde el PC, para probar que no te has cerrado la puerta:

```bash
ssh -o ConnectTimeout=10 sqx-hetzner 'echo SSH_SIGUE_VIVO'
```

## Prohibido

Abrir el 5050 ni ningún otro puerto; tocar `sshd_config`; cambiar claves SSH; parar
`novnc-display.service`; reiniciar el servidor; instalar nada fuera de `apache2-utils`.
