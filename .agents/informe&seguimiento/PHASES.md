## Phase protocol

For every phase:

1. Audit current implementation.
2. Define exact changes.
3. Delegate to specialized subagents.
4. Implement only the approved phase.
5. Run focused tests.
6. Run negative-path/red-team tests.
7. Review all diffs for hidden fallbacks, mocks or duplicated sources of truth.
8. Record evidence in `CURRENT_STATE.md`.
9. Mark `PASS`, `FAIL`, or `BLOCKED`.
10. Only `PASS` unlocks the next phase.

No phase may self-approve its own evidence solely from a unit test count. The phase requires behavioral verification.
