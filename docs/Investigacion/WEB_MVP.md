# Web MVP

## Pantallas

### Command Center

Campañas, presupuesto, workers, velocidad y errores.

### Live Leaderboard

Ranking canónico por multiplicador final, con una insignia clara para FAST frente a CANONICAL.

### Strategy Lab

DSL visual, parámetros, linaje, mutaciones y botón de validación canónica.

### Experiment Inspector

Equity, trades, eventos de funding, margen y liquidación.

### Evolution Tree

Árbol navegable de padres, hijos y saltos de rendimiento.

### Data Catalog

Versiones, huecos, checksums y ventanas.

### Research Inbox

Ideas pendientes, fuentes, hipótesis y estado de conversión a DSL.

## Regla UX

Nunca mezclar resultados aproximados con resultados canónicos. El usuario debe reconocer el nivel de fidelidad en todo momento.
