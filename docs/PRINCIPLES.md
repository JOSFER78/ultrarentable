# ULTRARENTABLE — PRODUCT & ENGINEERING PRINCIPLES

## Product identity

ULTRARENTABLE is a 24/7 autonomous quantitative research laboratory. It is not merely a backtester, leaderboard, dashboard or collection of six unrelated pages.

Its permanent loop is:

`GENERATION → QUALIFICATION → GATES → RESEARCH → VERSION → RE-EXAMINATION → CERTIFICATION → META-STRATEGY → LEARNING → GENERATION`

## ULTRA

ULTRA seeks extreme, asymmetric, high-convexity strategies across the supported universe, not only crypto. The track may use leverage, margin, pyramiding, recycling/compounding and bullet-style risk when explicitly supported by a policy.

The strategic research ambition is at least +100% monthly at the strategy/bullet level. This is an ambition used to search for exceptional candidates; it is not a fabricated guarantee and must never be implemented as a forced profitability rule.

## FONDEO

FONDEO seeks aggressive but rule-compliant strategies designed to pass real prop-firm evaluations quickly. The target is no more than 5 trading days for a viable strategy, subject to sufficient real evidence. The system may not relax validation, alter data, or shorten evidence to force a pass.

## Research

A promising failure enters Research. A structurally weak failure is discarded. Research can alter any strategy dimension, but every material change creates a new immutable version that must return to independent qualification.

## Learning

The system learns from:

1. observed failures;
2. observed successful experiments;
3. strategy genealogy and mutation outcomes;
4. cohort-level SQX fertility and robustness;
5. regime and execution patterns;
6. which research proposals generalize vs overfit.

Learning is persistent and evidence-linked.

## Meta-strategy

A meta-strategy is a first-class strategy-of-strategies. It combines compatible strategy versions across different assets/timeframes when joint evidence supports diversification or compensation. It may dynamically allocate risk using correlation, covariance, exposure, drawdown contribution, concentration and regime behavior.

Meta-strategies never erase constituent lineage. Every portfolio decision must be reproducible from the constituent strategy hashes and the meta-policy version.

## Absolute truth rules

- REAL DATA ONLY.
- ZERO MOCKS.
- ZERO INVENTIONS.
- ZERO SILENT FALLBACKS.
- ZERO FORCED PASS.
- ZERO FORCED PROFITABILITY.
- Missing evidence means BLOCKED / NO_EVIDENCE / NOT_COMPUTABLE.
- AI proposes; engines calculate; evidence proves; gates decide.
- The UI renders authoritative state; it does not invent or calculate domain truth.

## Version truth

A certification is contextual. It is tied to:

`strategy hash + dataset hash + engine version + compiler version + execution policy + risk policy + gate policy + evidence package`.

A material change makes affected certifications stale and eligible for automatic revalidation.

## Development truth

The codebase is implemented bottom-up. Each phase has:

`AUDIT → DESIGN → IMPLEMENT → TEST → ADVERSARIAL CHECK → EVIDENCE → CHECKPOINT`

No phase proceeds on an unverified assumption.
