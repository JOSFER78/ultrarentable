# BingX API Endpoints

- Contracts: `/openApi/swap/v2/quote/contracts`
- Trading rules: `/openApi/swap/v1/tradingRules`
- Klines: `/openApi/swap/v3/quote/klines`
- Mark klines: `/openApi/swap/v1/market/markPriceKlines`
- Premium/mark: `/openApi/swap/v2/quote/premiumIndex`
- Funding history: `/openApi/swap/v2/quote/fundingRate`
- Depth/trades: `/openApi/swap/v2/quote/depth`, `/openApi/swap/v2/quote/trades`
- User commission: `/openApi/swap/v2/user/commissionRate`
- Positions: `/openApi/swap/v2/user/positions`
- Orders: `/openApi/swap/v2/trade/order`
- Income: `/openApi/swap/v2/user/income`

Production: `https://open-api.bingx.com`
VST: `https://open-api-vst.bingx.com`
