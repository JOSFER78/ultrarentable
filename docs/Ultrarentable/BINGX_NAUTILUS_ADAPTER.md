# BingX NautilusTrader Adapter

BingX is not currently listed as an official NautilusTrader integration. Build a venue adapter following the official Rust-core/Python-layer architecture. Include HTTP signing, rate limits, GZIP WebSocket, Ping/Pong, listenKey lifecycle, instrument provider, market-data client, execution client, reconciliation, prod-vst and mock-server tests. CCXT is bootstrap only.
